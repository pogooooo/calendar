위젯 시안 — Celestial

홈 화면 위젯 11종을 Celestial 테마의 말로 다시 그렸다. 앱의 마름모·금빛 실선·Orbit 글꼴·월 게이지를 그대로 가져오고, 밝은 벌과 어두운 벌을 각각 두었다. 위젯은 앱의 테마(밝음·어두움)를 따르고, 테마 갈래가 늘면(다음: Maple) 위젯도 그 갈래의 옷을 입는다.

▸

만드는 법 · 목록

왜 지금 위젯이 밋밋한가. 안드로이드 홈 위젯은 앱의 화면(WebView)을 못 싣고, 쓸 수 있는 뷰가 TextView·ImageView·LinearLayout 정도뿐이다. 글꼴도 시스템 글꼴만 된다. 그래서 첫 판은 "글줄 + 점" 으로만 그렸다.

어떻게 이 시안대로 그리나. 앱(Kotlin)이 Canvas 로 위젯을 그림 한 장으로 그려서 ImageView 에 얹는다. 그러면 Orbit 글꼴(앱에 TTF 동봉), 마름모, 반원 눈금, 진행선까지 앱 화면과 똑같이 낼 수 있다. 누르는 자리는 그림 위에 투명한 칸을 겹쳐 PendingIntent 를 단다. 테마는 스냅샷에 theme: { family, mode, colors } 를 실어 보내, 갈래(celestial/maple)마다 다른 화가(WidgetPainter)가 그린다.

  1. 스냅샷 넓히기 — 이 달 끝까지의 일정, 기념일, 프로젝트, 오늘 메모, 테마 색을 widget-snapshot.json 에 더한다 (src/lib/widgetSnapshot.ts).
  2. 화가 — CelestialWidgetPainter: 종류·크기(칸 수는 onAppWidgetOptionsChanged 로 안다)·테마를 받아 Bitmap 을 돌려준다. 글꼴은 assets/fonts/Orbit-Regular.ttf.
  3. 종류 늘리기 — Provider 클래스 8개 추가 + 위젯 고르기용 미리보기. 크기별 줄 수는 화가가 정한다.
  4. 누르는 자리 — 줄·날짜 칸마다 투명 뷰 + PendingIntent. 앱 쪽은 cronos:// 딥링크로 "그 할 일 열기 / 그날 일간 / 추가 창" 을 받는다.
  5. 다시 그리는 때 — 지금처럼 파일 변경·앱 이탈·시각 경계 알람. "지금·다음" 과 "하루 진행" 은 진행 중일 때만 짧은 주기를 하나 더.
  6. 위젯 설정 화면 — 놓을 때 한 번 뜨는 WidgetConfigActivity(투명도 슬라이더 · 벌: 앱 따라감/밝음/어둠). 안드로이드 12+ 는 widgetFeatures="reconfigurable" 로 길게 눌러 다시 연다. 값은 위젯 id 마다 SharedPreferences 에 두고, 화가가 바탕을 칠할 때 그 알파를 쓴다.
  7. Maple 테마 — 갈래가 생기면 MapleWidgetPainter 를 하나 더. 종이 질감·단풍 마름모·먹색 글자로 같은 자료를 다르게 그린다.
